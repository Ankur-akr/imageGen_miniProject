# AI Image Generator (No DB) - Pollinations backend + React client

This project is a stateless image generator using Pollinations.ai.
- server: Express + Pollinations image proxy (no DB)
- client: React + Vite frontend (Netlify-ready)

Run locally:
1) Server:
   cd server
   npm install
   npm run dev
2) Client:
   cd client
   npm install
   VITE_API_URL=http://localhost:4000 npm run dev
